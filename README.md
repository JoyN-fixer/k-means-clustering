# K-means Clustering - Lab


This lab explored unsupervised learning using K-Means clustering. You generated a synthetic dataset with known structure, then applied K-Means to group the data without using the true labels.

You tested different values of k (from 3 to 7), evaluated model quality using inertia (WCSS) and the Calinski-Harabasz score, and visualized the results using elbow plots. These metrics helped identify where performance improvements slowed, indicating the optimal number of clusters.

Finally, you compared predictions to the ground-truth labels from the synthetic data and confirmed that the dataset likely contains about 6 clusters, showing how clustering can recover hidden structure in unlabeled data.
